# 🗓️ Linear Calendar 2026

Landscape printable calendar with vertical weekend alignment.

## 🛠️ Docker Instructions
1. Build locally: `docker build -t calendar .`
2. Run: `docker run -p 3000:80 calendar`
3. Access at `http://localhost:3000`

## ⌨️ Controls
- **Double-Click:** Action depends on active tool.
- **Eyedropper:** Double-click a cell to copy its color to your brush.
- **Print:** Use "Landscape" mode and enable "Background Graphics" in your browser print settings.
